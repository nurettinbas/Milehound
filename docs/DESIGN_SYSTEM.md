# Design system — Liquid Glass

Trailhound’s shell is a saturated atmosphere gradient with frosted glass cards. Settings → Appearance includes a **20-color palette**. One hue is stored; Light uses a vivid wash of that hue with **white type**, and Dark uses a deep shade of the same color. Default is **Sky**.

## Engine

`GlassEngineResolver` picks one renderer:

1. Reduce Transparency or `frozen` → **solid** fill (no Material resampling of a live map).
2. Dark → **material** (legacy).
3. Light + iOS 26+ + `allowsNative` → **native** (`glassEffect` + `GlassEffectContainer`).
4. Otherwise → **material**.

Light cards, Stats full/half cards, grouped list rows (`glassRow`), and Badges gallery cells use native `glassEffect` **behind** the content so the atmosphere shows through as colored glass — not a milky white plate and not a frost over type. Clip/mask the **plate** to the card; do **not** clip labels (corner type such as Name must stay whole). Nested tiles, field wells, and unselected chips stay frost fills (not a second glass host). Horizontal chip rows inside a card use `.glassChipScroller()` so the `HStack` can compress and plates stay inside the trailing corner; put `GlassChipGroup` around the chip `HStack` inside the `ScrollView`, never around the scroller. Pin with `allowsNative: false` or `frozen:` for camera, map overlays, share rasters, and the Badges **expand morph** plate. Budget: at most eight native glass hosts on screen; if Stats/Trips/gallery scroll drops below ~58 fps, pin that surface. `GlassChipGroup` still batches **selected** chip hosts; do **not** wrap a `List` or a row of `glassChrome` tiles in `GlassEffectContainer` (that milks the labels).

## Shape is not restyled

This is a color and glass-layer change. Spacing, padding, radii, fonts, minHeights, grids, animations, and accessibility identifiers stay put. The tab bar is the system iOS 26 `UITabBar` so Liquid Glass press and pill morph stay native. Never put `animation = nil` on `TabView` (that pauses `TimelineView.animation` on recap and onboarding). List-hosted motion (recording road, Start speed streaks, steering-wheel badge) uses `TrailhoundDisplayLinkTicker`, not `TimelineView`. The Start hound’s legs are the same `LaunchIntroHoundRig` Core Animation stride as the cold-launch intro. Recap / onboarding clocks use `TrailhoundIndependentClock.periodic`. The Stats filter card (`stats.filters.*`) is the shape reference. Form/list **and** Trip/Travel detail nav items use system toolbar metrics (the Trips cluster) instead of custom circles. A shared-platter pair (`GlassToolbarCluster(clustered: true)`) is tighter than two 44pt circles so the Trips inline title fits. Stats expand collapse and Year recap Share/Close are 44pt Liquid Glass circles (`GlassToolbarCollapseButton` / `GlassNavCircleIcon` / `.glassCircleChrome()`). Compact `.frozen` 36pt stays available for a smaller map chip.

## Accessibility

- Body copy on Light glass is white. Do **not** darken cards to force a WCAG 4.5:1 composite — that turns Forest/Gold into olive plates. Increased Contrast raises mid-family tint and rim, not white frost.
- Reduce Transparency uses `GlassEngine.solid` with opaque mid-family fill, not system grouped white and not chrome.
- Reduce Motion skips chip morph, sheen, card-press scale, forecast glint, toast emblem motion and glint (the card fades in), segment-bar grow-in, recap hub idle, recap promo teaser idle, recap intro title-card reveal, Play-chip pulse, badge flag-wave, distance path-node travel, night sky bob, the Start hound gallop (logo pose, streaks still), and the cold-launch gallop (a still logo crossfade instead). VoiceOver skips the launch intro. Tap anywhere to skip it.
- VoiceOver labels are unchanged. Palette swatches use `settings.shellPalette.<id>`.
- System exceptions stay system: `.alert`, Mail, share sheet, keyboard, Lock Screen widget, Live Activity. The CarPlay Dashboard Live Activity uses `.activityBackgroundTint(.clear)` (not `nil` — that is the default extra material) and no fill / compositing plate so CarPlay’s native Liquid Glass matches Now Playing. Floating tab bar is the system iOS 26 `UITabBar` in Light and Dark, portrait and landscape. Unselected glyphs stay the system ink. The selected tab uses the palette tint for that appearance.
- Legitimate blacks stay black: map vignette/dimming, delete/merge scrims, shadows, camera/crop stage. Semantic Stop/unread remains solid red.

## Wide layout

Phone portrait is unchanged. Every other size uses the same glass, type, and Liquid Glass buttons; only the arrangement changes. On the upright open fold the live recording card sits above the list, so it adds `recordingFoldExtraInset` (20pt on the inner Duo, one panel inset on a phone-width stacked fold) past its own 16pt padding and lines up with the trip plate. The scrolling phone list and split panes do not add that inset. iPad portrait keeps the recording card in a side pane, the same as landscape, so the card is not a banner stretched across the window. Travel detail on that same wide landscape, and on the open book, fills the leading pane with the member trips from top to bottom on the one atmosphere — no second wash and no sheet grabber — and the route map fills the trailing pane. A narrower landscape phone keeps the travel bottom sheet. iPad landscape keeps the trailing travel card. After a turn, fold, or unfold, the route glides back to the center of the map that is still visible. Upright open fold uses the phone sheet. A turn keeps that open trip mounted and does not fade the trip list over it. The sheet grabber stays on the phone overlay only. Upright open fold uses the phone sheet — map full screen, trip info below. Open landscape centers that recording card vertically in the leading half. On a wide landscape iPhone the Trailhound title hides while that card is up, the road uses the compact scene, and the four stats share one row so Pause and Stop clear the bottom tab bar. The Duo keeps the full road and the 2×2 grid. The road scene keeps its own height so its shadow stays above the timers. The live-map open control keeps the palette chip color and sits on a drop shadow so it lifts off the card. The card does not stretch to fill the pane. Recording stats stay the recording-card pills, arranged 2×2 in the side pane.

Profile fold, rotate, and map-mode changes with Instruments → SwiftUI → Animation Hitches while a recording is running. `PerformanceSignposts` emits `layout.reflow` when the class changes. A debug override is `UserDefaults` key `trailhound.layout.debugClass` (`phone`, `phoneLandscape`, `duoOpen`, `pad`) in Debug builds.

## Toasts

Confirmation toasts rise from the bottom. On the root shell they sit above the tab platter (`toastHost(clearsTabBar: true)` reads `SideColumnChromeState.tabBarFrame`). Sheets and full-screen covers use the bottom safe area. A side tab bar does not add bottom clearance.

The card is Liquid Glass (`glassChrome`, `GlassTokens.toastCornerRadius` 22, min height 56, max width 360) with a 38 pt emblem disc: gradient fill, white rim, 17 pt bold white symbol. Each `ToastKind` picks its own symbol, `ToastSymbolAnimation` (bounce, wiggle, pulse, rotate), and `ToastEmblemTone` (success green, destructive, warning, palette, gold). The disc scales and rotates in with `pinPop`, then the symbol effect plays. A one-shot `glassEntranceGlint` crosses the card. Reduce Motion fades only.

`TrailhoundHaptics.playToast` matches the kind: success, destructive, warning, merge, automation, personal record. UI tests skip haptics and the glint. VoiceOver reads the same message string as the label.
